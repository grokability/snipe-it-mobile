# Snipe IT Mobile

A WIP Snipe IT Mobile app project written in React Native using Expo. 

## Installation
1. Clone Repo
 - `brew install yarn` if not already installed
2. `yarn install`
3. `npx expo run:ios --device` `npx expo run:android --device` 
4. Ask Spencer for an invite to expo
5. Sign in to the cli tool using `npx expo login`
