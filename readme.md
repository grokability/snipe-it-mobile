# Snipe IT Mobile

## Installation
1. Clone Repo
 - `brew install yarn` if not already installed
2. `yarn install`
3. `yarn start --clear`
4. Ask Spencer for an invite to expo
5. Sign in to the cli tool using `npx expo login`
6. Download the Expo Go mobile app for testing camera-related things
7. Sign in with your expo account
8. Start the server again (`yarn start --clear`)
9. Select your dev server in the mobile app
